# ClassUp — Gamification prototype

ต้นแบบเว็บแอปสำหรับมือถือ: Login, คะแนน, Leaderboard แยกวิชา/กลุ่มเรียน, Badges และอวาตาร์

**ข้อมูลทุกคนและคะแนนในต้นแบบเป็นข้อมูลสมมติ ไม่มีข้อมูลนักศึกษาจริง ไม่มีการเชื่อมบัญชีจริงหรือ Google Sheets**

## ทดลอง

- เปิด `index.html` หรือให้ static server เสิร์ฟโฟลเดอร์ repository
- ใช้บัญชี `demo` / `classup` หรือกด **ลองเล่น ClassUp**
- อวาตาร์ นามแฝง และเป้าหมายบันทึกใน localStorage ของเบราว์เซอร์นี้เท่านั้น
- ไม่ต้องติดตั้ง dependencies หรือ build

## คะแนนรวม 100

| ส่วน | เต็ม | สถานะเริ่มต้น |
|---|---:|---|
| เข้าห้องเรียน | 5 | กำลังเก็บคะแนน |
| กิจกรรมในห้องเรียน | 15 | กำลังเก็บคะแนน |
| Final Project | 20 | ยังไม่ได้นำเสนอ |
| กลางภาค | 30 | ประกาศผลแล้ว |
| ปลายภาค | 30 | ยังไม่สอบ |

ค่าที่ยังไม่ประเมินเป็น `null` ไม่ใช่ 0 คะแนน น้ำหนักคะแนนไม่ใช่เปอร์เซ็นต์ความสำเร็จของเวลาเรียน

## Leaderboard และ Badges

- ใช้คู่รายวิชาและกลุ่มเรียนแบ่งกระดานอันดับ
- Bronze–Diamond ใช้ percentile 20, 40, 60, 80 ของห้อง
- Supreme คืออันดับ 1–5 (ระบบจริงต้องรวมคะแนนเสมออันดับ 5)
- กระดานใช้ชื่อสมมติ/นามแฝง แสดงตำแหน่งของผู้ใช้ และกรองใกล้ฉันได้
- Badges การเรียนมีเกณฑ์ที่มองเห็นได้: คะแนนเข้าเรียน, กิจกรรม, การประกาศผลสอบ, Project
- เหรียญสำรวจแอปและเป้าหมายส่วนตัวไม่มีผลต่อคะแนนเรียน
- เกณฑ์ Badges เป็นข้อเสนอสำหรับทบทวนก่อนใช้งานจริง ไม่ใช่เกณฑ์รายวิชาที่อนุมัติแล้ว

## GitHub Pages

ไปที่ **Settings → Pages → Build and deployment → Deploy from a branch**
เลือก **main / (root)** แล้ว Save. ไฟล์ `.nojekyll` ทำให้ให้บริการ static files ได้ตรง ๆ

## สถาปัตยกรรมระยะถัดไป

GitHub Pages ให้บริการ HTML/CSS/JS → Apps Script ตรวจบัญชี/สิทธิ์ → Google Sheets

ดู `docs/integration-plan.md` สำหรับ mapping คอลัมน์และข้อกำหนดการเชื่อมจริง
ต้นแบบยังไม่มี API client หรือ backend authentication เพื่อไม่ทำให้การทดสอบดูเหมือนเข้าสู่ระบบจริงได้

## แนวคิดการออกแบบ

- Autonomy: เลือกอวาตาร์ นามแฝง และเป้าหมายเอง
- Competence: เห็นคะแนนแยกส่วน เกณฑ์ระดับถัดไป และความคืบหน้า Badges
- Relatedness: ดูเฉพาะห้องเดียวกัน ใช้นามแฝงและภาษาที่ไม่ตีตราผู้มีคะแนนน้อย

อ้างอิง: [Niemiec & Ryan (2009), Self-Determination Theory in education](https://selfdeterminationtheory.org/SDT/documents/2009_RyanNiemiec_TRE.pdf)
